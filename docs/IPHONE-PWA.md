# AUTOMA X no iPhone

## Instalar na Tela de Início
1. Abra https://automa-x-interface.onrender.com no Safari.
2. Toque em Compartilhar (ícone de quadrado com seta para cima).
3. Role a lista e escolha **Adicionar à Tela de Início**.
4. Mantenha o nome AUTOMA X e toque em **Adicionar**.
5. Abra o ícone AUTOMA X pela Tela de Início.

## Atalhos úteis no app Atalhos
Crie atalhos do tipo **Abrir URLs** para:
- Painel: https://automa-x-interface.onrender.com
- API (estado público): https://automa-x-api.onrender.com/health/ready

Não coloque API_ACCESS_TOKEN, senhas ou códigos dentro de atalhos compartilháveis.
A API privada exige autenticação; o atalho de estado público não executa ações.

## Limites
O modo instalado dá acesso rápido ao painel. O iOS não permite que uma página controle livremente outros aplicativos ou execute ações em segundo plano sem autorização. Aprovações, login OAuth e publicação continuam sujeitos às permissões oficiais.
